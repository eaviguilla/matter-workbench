Where the data is

Real names, emails and addresses are stored as plain text in each client's client.json, in the data folder on this computer. Keep disk encryption on (FileVault or BitLocker), and do not share that file. To report a problem, run python -m app.check. Its report holds no stored values.

Download history

Open a client, then More, then Manage client, and choose "Download history with real names (.md)". The file has real names restored, so save it only where you control access.
